# Leads Meta RP Motos

Painel estático com o funil do CRM dos leads do Meta Ads da RP Motos: números gerais, etapas do kanban,
tempo até a primeira mensagem, motivos de perda e diagnóstico.

- Página única: `index.html` (sem build, sem dependências além da fonte Manrope).
- Os dados estão dentro do `index.html` (cópia fixa de 13/11/2026, sem nome, telefone ou id de lead).
- Filtros: data de entrada, dia da semana e MQL (marcação da planilha de leads).
